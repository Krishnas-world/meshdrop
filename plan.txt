# MeshDrop - Project Documentation

## Overview

MeshDrop is a cross-platform peer-to-peer file sharing application built using:

* Tauri v2
* React + TypeScript
* Rust
* TCP Networking

Goal:

Provide an AirDrop / Nearby Share style experience across Windows, Linux, and macOS without requiring cloud storage.

Files are transferred directly between devices over local network connections.

# Packet Types

## Implemented

Message = 1

Used for:

* Test messages
* Debug communication

---

FileOffer = 2

Used for:

* File transfer requests

Payload:

transfer_id|filename|filesize

Example:

1e168033-cc93-4995-8fba-e662ce9f3fd8|LLR.pdf|81693

---

FileAccept = 3

Used when receiver accepts a transfer.

---

FileReject = 4

Used when receiver rejects a transfer.

---

FileData = 5

Used for actual file contents.

Contains:

* Filename
* File Bytes
